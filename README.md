# Power BI Projects

Independent, from-scratch Power BI work — the questions, the data models, and every
design decision are my own. This is separate from my guided tutorial builds, which
live in another repo and exist to practice tooling rather than demonstrate judgment.

Each subfolder is a self-contained project with its own README and documentation.

## Projects

- `sakila/` — Data modeling and visual storytelling with the Sakila database.
  Turns a normalized OLTP schema into a star model and builds message-driven
  dashboards, each starting from a business question rather than a chart type.
  See the folder's README for the full approach.

## Principle

I work message-first: why (audience and takeaway) before what (the question and
comparison) before how (model, transformation, and finally the chart). The visual
is an output of the message, not a starting point.
